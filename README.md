# McAllister Journal

This project is a single-page interactive historical journal and navigation map for the voyages of Captain George C. McAllister between 1831 and 1833.

The page in `index.html` presents:

- a voyage map with daily coordinate markers
- vessel filtering for the different ships
- a guided tour through key milestones
- a journal reader panel that highlights log entries and narrative context
- a historical, parchment-style presentation inspired by maritime logbooks

## Purpose

The goal is to make the journal more accessible and engaging by combining geographic movement, journal excerpts, and context into one visual experience.

## Run locally

Open `index.html` in a browser to view the project.

If you want to serve it locally instead, you can use a simple static server from the project directory, for example:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
